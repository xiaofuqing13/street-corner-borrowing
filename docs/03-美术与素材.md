# 美术与素材制作规范

版本：登记簿视觉 v0.2；日期：2026-10-23。本轮按用户要求重做美术与界面，正式定稿以实际运行画面和手机体验为准。
目标是精美、可读且一致的完整作品，不以图片数量替代质量。

## 视觉定位

以当代中国普通社区借物站为背景：朴素服务柜台、借用登记簿、两把收拢的雨伞和一辆手推车。
读者应能直接理解借伞、借推车的用途。生活物件的形状、比例与连接结构必须可信。
采用明确线条与有限平涂色的二维叙事插画，使用中性自然光；精美来自造型和构图的一致性。
界面以纸白、墨色和少量重点色组织信息。去掉旧稿的青橙电影灯光、雨滴玻璃、反光材质和过量植物。
不堆叠巨大圆角卡片、胶囊标签、圆形姓名首字或通用治愈口号。色彩不能成为唯一状态提示。
旧场景图保留为制作记录，不作为本轮正式美术标准。

## 专属界面模板

已确认竖屏。界面采用借用登记簿的层级，安全区和滚动区域使用原生 UI 组件；手机真机验收尚未完成。
一个阅读页面始终同时支持以下信息层：
1. 当前时刻与班次：第一眼能判断自己正处理哪一轮。首页使用小幅插画，游玩页不放装饰场景图。
2. 当前人物和短请求：说明借什么、何时归还。
3. 可用库存、归还时间线、未来到访预告：直接呈现决策依据。
4. 两个明确动作：按当前条件借出，或礼貌婉拒。
5. 本轮结果与最近借用记录：便于复盘与中断后返回。

界面所有中文、按钮、库存数字、时间线、可访问名称与状态由游戏 UI 绘制。
图片中不得生成假按钮、假的库存数字、难以校对的小字或被误认为可点击的装饰。
概念插画可预留可排版区域；不把概念插画当成已经实现的游戏界面。

## 素材分工

- 主场景：普通社区服务窗口，固定柜台与借物用品，细墨线和平涂色，避免靠光效堆气氛。
- 常驻人物：职业和年龄仅用于故事，不作为真假、危险或好坏的暗号。
- 物件：雨伞和手推车优先，清楚轮廓和统一视角。
- 事件/结局插图：复用场景与角色，不为每句文字另画一张图。
- 音效：借出、归还、翻单、结算和基础按钮反馈；柔和、可独立关闭。
- 字体：先核实平台可用字体及授权，不擅自打包系统字体。
- 正式商店图：使用实际游戏画面配合排版，概念图不能伪装实机截图。

## AI 生成标准流程

1. 写明资产用途、内容、构图、视角、光照、材质、可读性要求及禁止项。
2. 先生成一张场景母版；概念样张标明“未定稿”。
3. 对母版检查透视、物件结构、人物手部、轮廓、文字残留和背景杂讯。
4. 母版通过后，后续资产以它作为风格参考，不在每次生成中改换风格。
5. 同一人物固定外貌与服装，不靠重新随机生成维持一致性。
6. 一次只针对明确问题修订；保留版本，不覆盖未经确认的旧稿。
7. 保存真实原始输出尺寸与文件信息，不把放大后尺寸冒充原生细节。
8. 写入素材台账：编号、来源方式、工具、提示词文件、用途、尺寸、哈希、状态。
9. 检查缩小到目标屏幕后是否仍清楚；落地后再检查裁切、安全区与加载表现。
10. 最终素材与必要授权/来源记录一并入库，临时变体放 work/。

按项目 canvas model-settings 的有效配置选择生成通道。本轮 generation.source=maker，使用官方 generate_image、model=default，不自行切换供应商。旧版场景来源为内置 imagegen。
本规范不宣称工具支持未公开的质量、种子或固定分辨率参数；只使用已核实能力。

## 通过标准

- 主体、物件与叙事用途一致，不出现无用装饰造成误解。
- 雨伞结构、推车轮轴和把手可信，无熔化、断裂、重复部件。
- 明暗与色彩为文字阅读服务，长时间观看不刺眼。
- 所有导出与参考保持同一角色、空间方向和笔触语言。
- 无其他游戏图标、品牌标识、第三方水印或照搬的角色设定。
- 概念稿、待修订、可用素材、已接入素材四种状态明确区分。
- 精美仅是一个通过项；不以美术通过代替玩法、真机或商业验证。
