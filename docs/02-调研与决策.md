# 调研与决策

检索日：2026-10-23。暂定项目名：《街角借物所》。本文记录选型依据与待验证假设，不构成收益承诺；具体数值以规则文档及试玩结果为准。

## 1. 当前决策

采用大众能理解的社区借物场景，以短文字事件和公开排期构成策略。首版只保留雨伞、手推车两类物品，在有限回合中安排借出、归还和到访预告。玩家需要判断“现在借给谁、什么时候能收回、是否要为之后的到访需求留库存”。不做真假鉴别、长篇分支小说、长期养成或复杂经营。

此选择主要基于交付可控性：一个场景与一套排期规则能够承载变化，减少持续制作大量新系统的压力。它尚未证明有足够需求，也尚未证明竞争较弱。

## 3. 本作的规则差异

关键不在“社区题材配卡片”，而在**借出会占用未来的一段时间**：物品离开库存后，仍以公开的归还节点出现在时间线上；未来到访预告也提前可见。玩家操作的对象是资源的可用时段，而不是抽象好感度。

例如：17:00 有两把伞，一位邻居承诺 17:30 归还，另一位要用到 18:30，而 18:00 有到访预告。接受两项请求是否合理，应由库存和时间关系解释。结果必须能回溯到玩家看到的信息，不能临时改变归还规则制造失败。

这是一项待验证的规则组合，不宣称全市场首创。只增加新名字、AI 插画或生活化文案，不足以形成差异。若竞品核查发现同平台已有强势产品提供相同排期体验，应调整或淘汰候选。

## 4. 市场证据的使用边界

中国游戏产业报告显示，2026 年上半年小程序游戏广告变现收入为 105.20 亿元，同比增长 31.94%。这是行业规模，覆盖多平台与产品，不能外推为个人开发者成功率、TapTap 制造收入或仅激励视频的收入。

来源：2026-07-30 发布的《2026年1-6月中国游戏产业报告》，上海市网络游戏行业协会刊载全文：https://www.oga.org.cn/newsinfo/9170782.html

腾讯广告与 TMI 的消除小游戏研究强调玩法、难度、流畅性以及广告与实际内容一致的重要性。其在线调查于 2025 年 9—10 月执行，样本 3,378 人，其中消除用户 2,245 人。它研究的是消除用户，不能直接代表文字策略玩家；动物、食物等题材偏好也不能作为本作选题成立的证据。

## 5. 立项后必须验证的假设

| 假设 | 验证方式 | 否定信号 |
| --- | --- | --- |
| 大众能理解排期 | 让未参与开发的目标玩家完成教学及完整一局，观察是否独立读懂库存、归还和到访预告。 | 反复解释仍把借出理解成永久扣除，或无法预测下一回合库存。 |
| 规则支持重玩 | 观察是否主动再玩，记录选择差异、重复事件感受与回访行为。 | 只称赞图片、一次看完就失去兴趣，或选择长期没有实际取舍。 |
| 存在可进入的小切口 | 在 TapTap 及相关移动渠道核查借物、预约、调度等近邻，比较核心规则、局长、更新与体验。 | 相同玩家已有满意替代品，本作优势仅为包装变化。 |
| 可选广告有价值 | 无广告闭环完成后，测试自然停顿处的有限补救；记录主动观看、有效完成、一次发奖及退出情况。 | 不看难以正常完成、奖励替代主要策略，或加入后重玩与留存恶化。 |

目前需求、低竞争、广告收益均待验证。搜索结果少不等于蓝海；评分、关注、销量或内购收入也不能替代 IAA 数据。收益判断须基于实际用户、有效广告结算及获客成本。

## 6. 美术与宣传决策

AI 优先用于统一风格的场景、人物和物品插画，先验证少量样张，再扩展素材。文字、按钮、库存和时间线由可编辑 UI 呈现，保证小屏清晰及状态准确。宣传图必须展示实际规则，不绘制不存在的经营、装饰或剧情功能。高品质以辨识度、风格一致、操作可读性及真机表现验收，不以图片数量或精细度替代游玩质量。
