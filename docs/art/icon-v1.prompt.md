# 首发图标制作记录

Maker generate_image；generation.source=maker；model=default；2K生成档位；输出缩放为1024×1024。参考station-v2的画法，不复制场景。

为原创竖屏手机文字排期游戏《街角借物所》绘制正式游戏图标，正方形，适用于应用列表的小尺寸展示。以参考图的深灰细墨线、平涂有限颜色和轻薄纸感为风格依据，只参考画法，不复制窗口场景。
主体是一把灰蓝与一把砖红的收拢长柄伞，并排但稍有高低地靠在一本合上的米白借用登记簿旁。两把伞的弯柄、伞骨轮廓和束带准确，登记簿造型简洁，侧边露出一个小纸质索引签。构图集中、轮廓鲜明，用深灰轮廓在浅米白背景上形成足够对比，中央80%为全部主要内容，边缘留12%安全空间，缩到64像素仍能读出两把伞与一本簿子。色彩只用灰蓝、砖红、纸白、墨灰，阴影是简单的一块浅灰平涂。
精美来自轮廓、线条和面积比例的一致性，像精心绘制的生活题材插画标志，有温度但不幼稚。不要摄影、3D、渐变、高光、金属反光、发光、体积光、景深、琥珀暖灯、复杂背景、装饰植物、泛黄污渍。不要文字、字母、数字、品牌、水印、按钮、手机外框或自行绘制的圆角图标外框。保持正方形完整不透明背景，平台以后会按需要裁角。不得模仿已有游戏图标或具体艺术家。
