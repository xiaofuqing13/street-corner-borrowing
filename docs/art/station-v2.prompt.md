# 场景插画 v0.2 制作记录

通道：Maker generate_image；model=default；quality=max；resolution=2K；target_size=1536x1024；aspect_ratio=3:2。目标尺寸是生成后缩放尺寸，不宣称是模型原生尺寸。

为原创手机文字策略小游戏《街角借物所》创作一张真正具有插画作者取舍的二维场景插画，用在借用登记簿风格首页的小幅横图。画面是当代中国普通老社区的一间小借物站，从街边看向敞开的简洁服务窗口：一张朴素木柜台，一本展开但完全无字的借用登记簿和一支笔；柜台右边靠墙放着两把收拢的长柄伞，颜色分别为灰蓝与砖红；旁边是一辆结构准确的折叠两轮载物手推车，轮子、承重板与把手的连接清楚。窗外只有一点普通楼房和树影的概括，不出现城市景点。没有人物。
视觉必须是手绘叙事插画：深灰铅笔或细墨线，线条有轻微真实的粗细变化但结构准确，平涂的米白、石灰灰、灰蓝、少量砖红，轻薄纸纹，色块边缘干净。构图稍不对称、有明确疏密和留白，像一本当代生活题材插画书中的场景，画得细心但不把每个表面填满纹理。生活实物尺度可信，空间透视清楚。采用阴天的自然漫射光，整体明亮、中性，少量柔和投影。横向3:2构图，主要物件集中在画面中央80%和垂直中央，手机首页横条裁切后仍能辨认伞和推车。画面本身不要画边框和页面UI。
禁止摄影写实、3D渲染、游戏概念场景套图、厚重数字油画、黄金暖光、青橙电影调色、体积光、发光边缘、镜面反射、雨滴玻璃、景深虚化、梦幻咖啡馆、植物堆满角落、强行做旧污渍、装饰海报。禁止文字、字母、数字、标识、水印、假按钮。不要模仿任何具体在世画家或现有游戏IP。精美来自造型、线条与构图的一致性，而不是光效与细节堆砌。
