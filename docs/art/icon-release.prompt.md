# 正式图标规范修订

依据后台素材库图标要求：≥512方图，JPG/PNG，不得白底、黑底、透明底，不自行切圆角。沿用Maker生成通道，model=default，目标1024×1024。

创作一张正式游戏图标，1024×1024正方形，供竖屏文字排期游戏《街角借物所》使用。参考图只作为深灰墨线与克制生活插画画法的参考，重新构图，不复制服务窗口。
图标的底必须是连续铺满画布的中等明度灰蓝色（约#7C9499），所有四角和边缘都是同样灰蓝，不可白底、黑底、透明底。主要画面是一册略向右倾的米白纸质借用登记簿，旁边一把砖红和一把深蓝的收拢长柄雨伞，伞弯柄方向和高低稍错开，簿子一侧露出小索引签。主体形成紧凑、易识别的整体，中央80%布局，小尺寸轮廓仍清楚；边缘留安全空间。
用清晰的深灰墨线、平涂色和极轻的铅笔纸感，阴影只用一块更深灰蓝的简单平涂。物件结构正确，图形取舍明确，避免细节堆砌。物件与底色有充分对比。画面正式、质朴，像手工绘制的生活题材标志。不要文字或空白题字区域，不要数字、品牌、手机外框、水印、圆角外框。不要白底/近白底、黑底、透明背景、渐变、3D、摄影、金属反光、高光、发光、体积光、梦幻暖灯、复杂场景、植物或污渍。输出完整不透明方图，禁止自行切圆角。
