# 街角借物所

当前状态：已建立并绑定 TapTap Maker 工程，已实现竖屏内部试玩版；正在重做登记簿风格的界面与场景插画。尚未完成真机和正式发布验收。用户已于2026-10-24明确要求先提审无广告版，广告开通后更新。
更新日期：2026-10-23（Asia/Shanghai）。

## 玩法

玩家在社区借物站安排两把雨伞和一辆手推车。每半小时处理两笔来访，先归还、再接待；16:00—18:30 共六轮，19:00 只归还和结算。
归还时刻与后续来访公开。借出和婉拒都会推进当前请求，没有隐藏的道德惩罚。三个固定班次各有十二笔请求，均有十笔借出的最优排期。

## 工程

- `scripts/main.lua`：原生入口、界面控制、双槽本地记录、云存档冲突选择与音效。
- `scripts/content.lua`：人物、三个班次与借还时间表。
- `scripts/game.lua`：纯 Lua 规则、快照与重放恢复。
- `scripts/view.lua`：原生 UI 组件构建的首页、游玩、到访表、规则、设置与结算。
- `assets/image/`、`assets/audio/`：运行素材；素材与提示词记录见 `docs/`。
- `engine-docs/`、`examples/`、`templates/`、`urhox-libs/`：官方 dev-kit 参考资料，不作为用户源码修改。
- `work/`：被 Git 忽略的临时工具、日志与测试证据。
